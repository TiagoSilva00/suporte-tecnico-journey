# Glossário — Suporte Técnico / Help Desk / Service Des

Termos e conceitos aprendidos ao longo da jornada, em Português e Inglês, 
atualizados a cada nova sala/tópico concluído.

---

## Windows Fundamentals

**BitLocker** — Recurso de criptografia de disco completo, disponível nas 
versões Windows Pro, Enterprise e Education (não disponível na versão Home).

**NTFS (New Technology File System)** — Sistema de arquivos padrão das 
versões modernas do Windows. É um sistema "journaling", ou seja, registra 
alterações para permitir recuperação em caso de falhas. Sucessor do 
FAT16/FAT32 e HPFS.

**Notification Area (Área de Notificação)** — Região da barra de tarefas do 
Windows (canto inferior direito) que exibe ícones de status e notificações 
rápidas, como relógio, rede, volume e Central de Ações.

**Action Center (Central de Ações)** — Ícone/painel na área de notificação 
do Windows que centraliza notificações do sistema e acesso rápido a 
configurações.

**Taskbar (Barra de Tarefas)** — Barra horizontal na parte inferior da tela 
do Windows, contendo o menu Iniciar, caixa de pesquisa, aplicativos fixados 
e a área de notificação.

**Task View (Visualização de Tarefas)** — Recurso do Windows que exibe todas 
as janelas e áreas de trabalho virtuais abertas, permitindo alternar entre 
elas rapidamente.

**Guest Account (Conta de Convidado)** — Conta integrada do Windows 
destinada a acesso temporário/limitado por usuários sem conta própria no 
sistema.

**Gerenciamento do Computador (Computer Management)** — Ferramenta 
administrativa do Windows que reúne utilitários como Usuários e Grupos 
Locais, Gerenciador de Dispositivos, Visualizador de Eventos, entre outros.

## Virtualização

**VirtualBox** — Software de virtualização gratuito da Oracle, usado para 
criar e rodar máquinas virtuais (VMs) dentro de um computador físico.

**VM (Virtual Machine / Máquina Virtual)** — Ambiente de computador 
simulado por software, que roda um sistema operacional próprio isolado do 
sistema físico (host).

**ISO** — Formato de arquivo de imagem de disco, usado para distribuir 
sistemas operacionais completos (ex: instalador do Windows) prontos para 
gravação ou uso em máquinas virtuais.

**RAM (Random Access Memory / Memória de Acesso Aleatório)** — Memória 
volátil do computador usada para armazenar dados temporários em uso; fator 
crítico para desempenho ao rodar máquinas virtuais.

**Visual C++ Redistributable** — Pacote de bibliotecas da Microsoft, 
pré-requisito comum para instalação de diversos softwares no Windows 
(incluindo o VirtualBox).

## Plataformas de Prática

**TryHackMe** — Plataforma online de aprendizado prático em TI e 
Cibersegurança, que disponibiliza máquinas virtuais acessíveis via 
navegador, sem necessidade de instalação local.

**AttackBox** — Máquina virtual de ataque baseada em navegador, fornecida 
pelo TryHackMe para interagir com os laboratórios das salas sem precisar de 
VPN.

**Freshdesk** — Plataforma de help desk/ticketing usada para gerenciar 
chamados de suporte técnico, atendimento ao cliente e fluxos de trabalho de 
ITSM (Gestão de Serviços de TI).

---

## Conceitos de Suporte Técnico / ITSM

**Ticket (Chamado)** — Registro formal de uma solicitação, incidente ou 
problema reportado por um usuário/cliente, gerenciado através de uma 
ferramenta de help desk.

**ITIL (Information Technology Infrastructure Library)** — Framework de 
boas práticas para gestão de serviços de TI, amplamente adotado por 
equipes de Service Desk para padronizar processos como incidentes, 
problemas e mudanças.

**SLA (Service Level Agreement / Acordo de Nível de Serviço)** — Compromisso 
formal que define o tempo esperado de resposta/resolução para um chamado.
